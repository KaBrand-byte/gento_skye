# 2026-11-11 更正点位后的离线验证

本记录描述真机完整运行之前的离线验证。后续用户已完成整轮空载运行，并发现重复启动的短轨迹问题，见[后续实验与修复记录](2026-11-11-repeat-run.md)。

用户更正了此前临时填写的点位：准备位左右臂分别为 `[90,-64,-67,-89,-24,-8,17]`、`[-90,-64,67,-89,24,-8,-17]`，升降 500 mm；接盘位分别为 `[85,-70,-60,-90,15,0,10]`、`[-85,-70,60,-90,-15,0,-10]`，升降 450 mm。两点腰、头均为 `[0,0]`；前伸、下降均为 100 mm，侧向退出仍为各 100 mm。

使用本机原生 SDK `00040701`，从 SDK 自带 `CT040701/cfg_default_040701/GentoSkye-V3.0_M6SC-696-V4.0_00040701.ini` 读取出厂参数，通过 `init_single_arm_manual()` 初始化。两臂 TCP 均设为零，使用当前关节邻近逆解策略。全程未连接控制器、未下发任何真机运动指令。

从更正后的接盘关节和 450 mm 升降高度开始，调用与 `plan-check` 相同的计算流程；每段以规划终点作为下一段起点，检查轨迹首点连续性、末端位置和姿态误差，以及最终回准备关节值。

规划频率为 50 Hz，直线速度／加速度为 100 mm/s、100 mm/s²，MoveJ 速度／加速度比例为 0.1。准备到接盘的两臂首末关节误差均小于输出精度。与首次实验的旧配置相比，此次完整直线路径未复现 `-1020`。

升降不参与上述双臂规划，生产流程单独下发位置指令并检查反馈到位稳定。顺序为：双臂准备姿态 → 升降 500 mm → 双臂接盘姿态 → 升降 450 mm → 等待 Enter → 前伸／下降／退出 → 双臂准备姿态 → 升降 500 mm。升降过程中保持两臂不动，所有双臂运动过程中保持升降不动。

57 项单元测试通过，覆盖升降分段、到位、超时、取消、双臂漂移和停止保持等。出厂模型与设备实际参数可能不同，以上通过只表明本地运动学规划成功，未验证实际升降执行及路径碰撞。下一次设备验证应在接盘高度使用 `plan-check` 读取控制器实际模型和 TCP；更新后的完整流程尚未执行真机验证。
