## 5. 按任务查

- 接线、网络与默认 IP、开机与安全、整机规格 → 产品用户手册
- 双臂接口、控制模式、SDK 版本兼容、运动学与规划 → 1004 SDK 文档 + API 参考 + SDK 仓库
- 底盘建图标点、导航参数、任务派发、告警码 → 底盘四份（接口细节查 ROS 2 软件接口说明）
- PICO 采集、MCAP 录制、数据集转换、PI0/PI05 训练与部署 → Apex 文档中心

## 6. 使用注意

- 钉钉发布页正文可直接读取；图片走鉴权直链，需登录后在浏览器中查看或导出。
- 版本敏感：SDK 分支须与控制器固件 MAJOR/MINOR 一致；遥操的控制端、遥操服务与前端、头显客户端须为同一交付批次；底盘软件与本文档版本可能不同步。
- 本地副本可能落后于线上，冲突时以线上文档和设备实际行为为准。
